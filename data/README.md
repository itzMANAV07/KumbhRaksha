# data/

This directory contains the geographic data files for KumbhRaksha.

## Files

- `zones.geojson` — Zone polygons traced from OpenStreetMap (added in M1)
- `facilities.json` — Demo facilities with `demo: true` (added in M1)

## Rules

- Do NOT create or edit coordinates in code.
- If a file is missing, the app will log a warning and start with empty data.
- All coordinates must come from real OSM traces or geojson.io exports.
